# 공식 시나리오는 미션 콘텐츠를 담아 한 번에 v2로 올린다

Drill 확장([DRILLS_EXPANSION_PLAN.md](../DRILLS_EXPANSION_PLAN.md))이 INITIAL 단계에 요구사항 질의·규모 추정·가정·제약 콘텐츠를 추가하고, 요구사항 질의(M1)를 위해 INITIAL 프롬프트를 일부러 짧게 줄인다. 공식 7개 시나리오는 지금까지 전부 `version_no = 1`이었다.

**기능은 콘텐츠 필드가 없으면 나타나지 않게 먼저 구현하고, 공식 7개 시나리오의 v2를 하나의 마이그레이션으로 추가한다.** v1을 제자리에서 고치지 않는다. 버전 단위로 묶인 토론은 "이전 버전 토론"을 읽기 전용으로 함께 보여줘 v1 글이 사라지지 않게 한다(v2보다 먼저 배포).

**이유**: 대안은 (1) 꼬리설계 변형을 추가할 때(V14)처럼 v1을 제자리 UPDATE하는 것, (2) 한 도메인씩 검증하며 순차로 올리는 것이었다. (1)은 프롬프트를 줄이면 난이도가 바뀌는데도 같은 `scenario_version_id`로 묶여, 버전 단위로 비교하는 벤치마크와 토론이 서로 다른 문제를 푼 사람을 같은 모집단으로 섞는다 — V14는 프롬프트를 추가했을 뿐 기존 내용을 바꾸지 않아 문제가 없었다. (2)는 기능이 하나씩 추가될 때마다 같은 시나리오의 버전을 다시 올려 벤치마크 표본이 여러 번 초기화된다.

**대가**: v2 배포 시점에 공식 7개 시나리오의 벤치마크 표본이 한꺼번에 0이 되고, 표본 하한(n=5)을 다시 채울 때까지 비교가 표시되지 않는다. 도메인 최고점 기반인 Drill Score·인증은 버전과 무관해 영향이 없다. 되돌리려면 v2를 `status`에서 내려야 하는데, 이미 v2로 시작한 세션은 v2에 묶여 남는다.
